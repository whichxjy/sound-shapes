# Project documentation

This directory is the working specification for Sound Shapes.

- [Product brief](product.md): purpose, audience, interaction, content, and acceptance criteria.
- [Scientific model](science.md): what is drawn and played, what can be inferred, and what cannot.
- [Implementation decisions](implementation.md): current structure, data, accessibility, testing, and possible future changes.
- [Three-note chord study](triads.md): the implemented 3D view, reference cube, playback, pairwise projections, and tuning.
